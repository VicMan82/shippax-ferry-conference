# Shippax Ferry Conference app (prototype)

Installable web app prototype for the Shippax Ferry Conference, 20–22 April 2027.

- Android: open the link in Chrome, tap the three-dot menu and choose "Install app" (or "Add to Home screen").
- iPhone: open the link in Safari, tap Share and choose "Add to Home Screen".

This is a prototype. Data is stored on each phone only, push messages are shown inside the app, and delegates, messages and excursions are sample content.
